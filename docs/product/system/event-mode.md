# Event Mode (opcional) — Altezza (MiEvento)

> Fuente: `uploads/andres/inbox/2026-03-07T00-05-16-051Z__altezza_modulos_panel.md`

---


## Descripción general

Event Mode es un modo especial de funcionamiento de la plataforma diseñado para el **día real del evento** o las horas inmediatamente previas. En este momento la prioridad del sistema cambia: ya no se trata principalmente de planificar o editar información, sino de **consultar rápidamente datos críticos, coordinar al equipo y ejecutar el evento sin errores**.

Cuando Event Mode está activo, la interfaz del sistema reorganiza la información para mostrar primero los elementos operativos más importantes del evento.

Este modo está pensado especialmente para:

- coordinadores de evento
- equipo operativo
- colaboradores en campo
- clientes que desean seguir el desarrollo del evento

La activación de Event Mode no elimina módulos del sistema; simplemente **prioriza y reorganiza la información para facilitar la operación del evento en tiempo real**.

---


## Objetivos del Event Mode

El objetivo principal es convertir la plataforma en una **herramienta operativa en vivo** durante el evento.

Problemas que busca resolver:

- evitar que el equipo pierda tiempo navegando entre muchos módulos
- facilitar la consulta rápida de información crítica
- reducir errores durante el montaje o ejecución del evento
- permitir una coordinación más clara entre todos los participantes
- ofrecer una vista centralizada del estado del evento

---


## Cambios en la interfaz cuando Event Mode está activo

Cuando Event Mode se activa, la interfaz del sistema cambia su enfoque hacia un **panel operativo del evento**.

Características de la interfaz:

- encabezado visible con el nombre del evento
- indicador visual de que el sistema está en "Modo Evento"
- acceso rápido a los módulos más relevantes
- tarjetas grandes con información crítica
- menos navegación secundaria
- enfoque en acciones rápidas

Ejemplo de información visible en la pantalla principal:

- nombre del evento
- lugar del evento
- hora actual
- próximo momento del cronograma
- progreso de checklists operativos
- pendientes urgentes
- estado general del evento

---


## Información prioritaria mostrada en Event Mode

La pantalla principal del modo evento puede mostrar elementos como:

**Próximo momento del evento**

Ejemplo:

- 5:30 pm — Inicio de ceremonia
- 7:00 pm — Entrada de novios
- 8:30 pm — Primer baile


**Progreso de montaje o tareas operativas**

Ejemplo:

- Checklist montaje: 82% completado
- 3 ítems pendientes por cargar


**Pendientes urgentes**

Ejemplo:

- Confirmar micrófono del maestro de ceremonia
- Verificar iluminación de mesa principal


**Equipo activo en el evento**

El sistema puede mostrar cuántos colaboradores están conectados al evento.

Ejemplo:

- 3 colaboradores activos


---


## Módulos que toman prioridad en Event Mode

Cuando Event Mode está activo, los siguientes módulos pasan a ser los principales:

- 📅 Wedding Day
- ⏱️ Timming
- ✅ Pendientes
- 🧰 Colaborador Checklist Montaje
- 📦 Colaborador Checklist Recogida
- 📊 Dashboards operativos


Estos módulos contienen la información necesaria para la ejecución del evento.


## Módulos que pasan a segundo plano

Durante Event Mode algunos módulos dejan de ser prioritarios en la navegación principal, aunque siguen estando disponibles:

- 💡 Inspiración
- 🎨 Paletas Colores
- 🎂 Pastel
- 💍 Tips Boda
- 💌 Invitaciones

Estos módulos están más relacionados con la planificación previa del evento.

---


## Activación del Event Mode

El sistema puede permitir distintas formas de activar este modo:

**Activación manual**

El administrador o coordinador del evento puede activar Event Mode desde el panel del evento.


**Activación automática por fecha**

Si la fecha del evento coincide con la fecha actual, el sistema puede sugerir activar Event Mode.


**Modo híbrido (recomendado)**

El sistema detecta que el evento ocurre ese día y muestra una sugerencia al administrador:

"Activar modo evento para este evento"

El administrador decide si activarlo.

---


## Beneficios operativos

Implementar Event Mode aporta varias ventajas importantes:

- mejora la coordinación del equipo
- reduce errores en la operación del evento
- permite visualizar rápidamente el estado del evento
- facilita el trabajo desde celulares o tablets
- convierte la plataforma en una herramienta útil durante la ejecución real del evento


---


## Notas

Esta funcionalidad es **opcional** y puede implementarse en una fase posterior del desarrollo del sistema.

Sin embargo, su incorporación puede mejorar significativamente la experiencia operativa de Altezza durante la ejecución real de los eventos.
