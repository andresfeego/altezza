# 🏠 Admin Home

## Descripción

Panel principal del administrador que funciona como **dashboard general del sistema**. Desde aquí el administrador puede ver resúmenes, alertas y accesos rápidos a los diferentes módulos administrativos.

## Funciones

- Mostrar tarjetas (cards) con resúmenes de módulos administrativos
- Mostrar notificaciones o estados pendientes (por ejemplo alquileres por aprobar o cotizaciones pendientes)
- Accesos rápidos a los módulos más utilizados

## Notas

El dashboard se compone de **cards de resumen por módulo**, donde cada card puede mostrar indicadores relevantes para el administrador (ej: elementos pendientes, acciones por realizar, o estados recientes).
