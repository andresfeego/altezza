# 🏠 Admin Home

## Rol
ADMIN

## Descripción
Panel principal del administrador. Funciona como **dashboard general del sistema** con resúmenes, alertas y accesos rápidos a los módulos administrativos.

## Funciones
- Mostrar tarjetas (cards) con resúmenes de módulos administrativos.
- Mostrar notificaciones o estados pendientes (ej: alquileres por aprobar o cotizaciones pendientes).
- Accesos rápidos a módulos más utilizados.

## Notas
- El dashboard se compone de **cards de resumen por módulo**.
- Cada card puede mostrar indicadores relevantes (pendientes, acciones por realizar, estados recientes).
