# ⏱️ Timming

Descripción:
Módulo que permite definir el **cronograma del evento**, especificando las actividades que ocurrirán durante el día del evento con su hora y descripción.

Funciones:

- Crear pasos o actividades del evento
- Definir hora de cada actividad
- Agregar título del momento del evento
- Agregar descripción o detalles
- Editar o eliminar actividades
- Generar una URL pública del timming del evento

Notas:
El timming puede compartirse mediante una **URL pública** con personas clave del evento como:

- maestros de ceremonia
- encargados de sonido
- coordinadores del evento

Cada actividad del timming incluye:

- hora
- título del momento
- descripción

Plantillas de pasos:
Muchos eventos comparten una estructura similar de actividades. Por esta razón, el sistema permitirá administrar una **base de pasos de evento desde el dashboard de administrador**, donde se podrán definir:

- título del paso
- icono representativo

Estos pasos podrán reutilizarse al momento de crear el timming de un evento, facilitando y acelerando la construcción del cronograma.
