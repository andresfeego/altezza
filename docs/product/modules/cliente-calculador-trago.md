# 🍹 Calculador Trago

## Descripción

Herramienta que ayuda a estimar la cantidad de bebidas necesarias para el evento según el número de invitados y la duración estimada de la celebración.

## Funciones

- Ingresar número de invitados
- Definir duración estimada del evento
- Calcular cantidad aproximada de bebidas necesarias
- Mostrar estimaciones por tipo de bebida

## Notas

El módulo permite calcular y guardar una estimación de bebidas para facilitar la planificación del evento.

Preview - Cliente Home:
En el **🏠 Cliente Home** aparecerá una **card preview** del cálculo realizado.

La card mostrará:

- **Iconos por tipo de bebida** (ej: 🍾 vino, 🥃 licor, 🍹 cócteles, 🍺 cerveza)
- Debajo de cada icono la **cantidad configurada para el evento**

Ejemplo conceptual del preview:
🍾 Vino → 2 botellas\
🥃 Licor → 3 botellas\
🍺 Cerveza → 3 cajas

La card completa será **cliqueable** y llevará al módulo completo de **Calculador de Trago** para editar o recalcular las cantidades.
