# 💰 Admin Cotizador

## Descripción

Módulo donde el equipo de Altezza crea y administra **cotizaciones completas de eventos**. Las cotizaciones se construyen mediante un formulario por pasos que permite estructurar una propuesta visual y económica para el cliente.

## Funciones

- Crear nueva cotización
- Editar cotización
- Eliminar cotización
- Gestionar versiones de cotización
- Exportar o compartir cotización con el cliente

## Flujo de creación de cotización

El administrador entra a **Nueva cotización** y completa un formulario estructurado por pasos:

1. **Portada**

   - Datos del evento
   - Nombre del evento
   - Fecha
   - Lugar

2. **Mensaje inicial**

   - Texto de introducción (ej: "Hola soy Cindy Huertas")
   - Puede ser personalizado por cotización o utilizar un texto estándar

3. **Concepto del evento**

   - Descripción conceptual del diseño del evento
   - Estilo o narrativa del evento

4. **Paleta de colores**

   - Selección de colores del evento
   - Permite crear paletas manualmente
   - Permite extraer colores desde una imagen (mismo sistema del módulo **🎨 Paletas Colores**)

5. **Imágenes de referencia**

   - Galería de imágenes que representan la propuesta visual

6. **Menús**

   - Descripción de menús o propuesta gastronómica del evento

7. **Presupuesto**

   - Lista de conceptos
   - Valores individuales
   - Total del evento

8. **Condiciones**

   - Condiciones estándar del servicio
   - Posibilidad de modificar o personalizar condiciones

9. **Contacto**

   - Información de contacto de Altezza
   - Página o sección final estándar de la cotización

## Notas

El objetivo del módulo es permitir generar **documentos de cotización estructurados y visualmente claros** que presenten al cliente tanto el concepto creativo del evento como el presupuesto asociado.
