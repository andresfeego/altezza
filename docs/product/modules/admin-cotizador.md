# 💰 Admin Cotizador

## Rol
ADMIN

## Descripción
M�dulo para crear y administrar cotizaciones completas de eventos. Se construyen con un formulario por pasos y generan un documento visual y económico.

## Funciones
- Crear cotización.
- Editar cotización.
- Eliminar cotización.
- Gestionar versiones.
- Exportar o compartir cotización.

## Flujo de creación (pasos)

1. **Portada**
   - Datos del evento
   - Nombre
   - Fecha
   - Lugar

2. **Mensaje inicial**
   - Texto de introducción (ej: "Hola soy Cindy Huertas")
   - Personalizable o estándar

3. **Concepto del evento**
   - Descripción conceptual
   - Estilo/narrativa

4. **Paleta de colores**
   - Crear paletas manualmente
   - Extraer colores desde imagen (mismo sistema de **🎨 Paletas Colores**)

5. **Imágenes de referencia**
   - Galería de imágenes

6. **Menús**
   - Propuesta gastronómica

7. **Presupuesto**
   - Conceptos
   - Valores
   - Total

8. **Condiciones**
   - Condiciones estándar
   - Personalizables

9. **Contacto**
   - Información final estándar

## Notas
Objetivo: documentos estructurados y visualmente claros que presenten concepto creativo y presupuesto.
