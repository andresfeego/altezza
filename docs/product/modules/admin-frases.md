# 💬 Admin Frases

## Rol
ADMIN

## Descripción
Gestión de frases cortas inspiracionales o tipo consejo para mostrarse en partes de la plataforma.

## Funciones
- Crear frases.
- Editar frases.
- Eliminar frases.
- Activar/desactivar.
- Clasificar por categoría o uso.
- Asociar frases a tipos de evento.

## Clasificación

1) **Tipo de evento** (definido en base de datos)
- Boda
- Quince años
- Bautizo
- Evento empresarial
- Otros

2) **Categoría de frase**
Ejemplos:
- Para novia
- Para novio
- Para padres
- Para quinceañera
- Consejos generales

## Notas
- Estilo similar a consejos editoriales/Instagram.
- Ejemplo conceptual:
  - "El día anterior a tu boda trata de dormir bien..."
- Se usan en módulos como **💍 Tips Boda** y secciones informativas.
