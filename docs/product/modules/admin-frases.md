# 💬 Admin Frases

Descripción:
Módulo donde el administrador crea y gestiona **frases cortas de estilo inspiracional o tipo consejo**, pensadas para mostrarse en diferentes partes de la plataforma.

Funciones:

- Crear nuevas frases
- Editar frases
- Eliminar frases
- Activar o desactivar frases
- Clasificar frases por categoría o uso
- Asociar frases a tipos de evento

Estructura de clasificación:
Las frases podrán organizarse mediante dos niveles de clasificación:

1. **Tipo de evento** (definido en base de datos)

   - Boda
   - Quince años
   - Bautizo
   - Evento empresarial
   - Otros tipos de evento

2. **Categoría de frase**
   Permite mostrar frases dirigidas a diferentes protagonistas del evento.

   Ejemplos:

   - Para novia
   - Para novio
   - Para padres
   - Para quinceañera
   - Consejos generales

Notas:
Las frases tienen un estilo similar a publicaciones de **Instagram o consejos editoriales**, con redacción cercana y motivacional.

Ejemplo de frase:
"El día anterior a tu boda trata de dormir bien. No te estreses, pues eso se verá reflejado en tu piel y queremos que brilles en las fotos de este día tan especial."

Estas frases pueden mostrarse en diferentes módulos del sistema, como por ejemplo:

- **💍 Tips Boda**
- Secciones informativas dentro del evento
- Otras áreas de la plataforma donde se desee mostrar consejos o mensajes inspiracionales para los usuarios.
