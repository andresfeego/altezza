# 🪑 Admin Mobiliario

## Rol
ADMIN

## Descripción
Inventario de mobiliario disponible para alquiler. Alimenta el catálogo de alquiler que utilizarán organizadores.

## Funciones
- Crear ítems de mobiliario.
- Editar mobiliario.
- Registrar cantidad disponible.
- Subir fotos.
- Clasificar por tipo o categoría.
- Definir si es propio o de proveedor.

## Notas
- El mobiliario constituye el catálogo base de alquiler.
- Tipos de origen:
  - **Propio:** pertenece a Altezza.
  - **Proveedor:** pertenece a proveedor externo.
- Si es de proveedor, puede vincularse a un proveedor de **🧑‍🍳 Admin Proveedores**.

## Regla de visibilidad (organizadores)
- El catálogo para organizadores **solo incluye mobiliario propio de Altezza**.
- El mobiliario de proveedor se usa internamente o en planificación de eventos, pero no aparece en el catálogo público para organizadores.
