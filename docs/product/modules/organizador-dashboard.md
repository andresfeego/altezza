# 📊 Organizador Dashboard

## Descripción

Panel principal para los **organizadores externos de eventos** que utilizan la plataforma para gestionar alquiler de mobiliario proporcionado por Altezza.

## Funciones

- Mostrar resumen de solicitudes de alquiler
- Mostrar estados de alquiler (por cotizar, aprobado, confirmado, entregado, etc.)
- Acceso rápido al catálogo de mobiliario disponible

## Notas

Un **organizador** es un profesional o empresa que organiza eventos de manera independiente a Altezza. Altezza les presta el servicio de **alquiler de mobiliario**.

Actualmente este proceso se realiza de forma manual mediante catálogos y comunicación externa. La plataforma permitirá que este flujo se gestione directamente dentro de **MiEvento**, facilitando la selección de mobiliario, cotización, acuerdos de alquiler, registro de abonos, saldos pendientes y fechas del servicio.
