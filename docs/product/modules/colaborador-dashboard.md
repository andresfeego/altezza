# 📊 Colaborador Dashboard

Descripción:
Panel principal para el personal operativo que trabaja en el evento. Desde aquí los colaboradores pueden ver rápidamente las tareas del día, los eventos asignados y los checklists que deben completar.

Funciones:
- Ver eventos asignados al colaborador
- Acceder rápidamente a los checklists de **alistamiento** y **recogida**
- Ver resumen de tareas pendientes del evento
- Ver horario del evento o agenda del día

Notas:
El objetivo de este dashboard es ofrecer una vista simple para el equipo de trabajo que se encuentra en campo, permitiendo acceder rápidamente a las tareas necesarias para preparar y cerrar el evento.
